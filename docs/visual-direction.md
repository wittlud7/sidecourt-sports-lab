# 场边：刊物式体育工作台

本轮将首页改为文字与摄影分栏的刊物封面，资料概况改为连续的数字栏；比赛日采用赛程与细节摄影对照，下半部分以场馆画面和编排式目录组织图谱、研究、备课及游戏入口。比赛、球员、球队和备课页使用各自的图片与引言版式。

色彩：暖纸白、墨色、酒红、木色。字体层次由中文衬线标题与易读的无衬线正文构成。手机切换为单栏；图片保持独立画幅，重要按钮与数据不叠在复杂图像上。

## 提示词组

共同规格：高水平体育编辑摄影、自然材质、胶片颗粒、真实球体与人体结构、无文字、无品牌、无水印，不生成界面。

1. 足球对抗：贴近地面的雨夜专业足球对抗，酒红与象牙白球衣，聚焦鞋、腿、足球与飞溅水滴，琥珀色灯光和冷雾，深绿草地，电影感构图。
2. 篮球对位：高位俯视木地板上的跳投与防守，象牙白和酒红球衣，下午日光与几何长影，球员位于右侧，左侧保留木地板空间，建筑式极简构图。
3. 足球细节：象牙白足球、酒红缝线、露水草地和白色边线，远处球员通道的暖光与晨雾，低机位微距、克制的静物构图。
4. 篮球细节：旧橙色篮球、木地板、场边旧木长椅和奶白训练毛巾，一束下午光与悬浮尘埃，棕褐色及酒红阴影，具有使用痕迹的静物摄影。
