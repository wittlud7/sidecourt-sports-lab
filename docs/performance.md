# 按需加载与首屏预算

2026-10-25，将历史球员完整档案从译名模块中拆出，游戏、图谱、战术、备课、研究及详情面板改为按需加载。首页只携带轻量译名与工作台基础代码。

同一浏览器的生产首页 JavaScript 测量，按 Resource Timing 的 `decodedBodySize` 求和：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 首页应用主包 | 1,360,623 B | 33,324 B |
| 首页初始 JavaScript 总计 | 1,744,745 B | 669,667 B |

总计减少约 62%。这是解压后的 JavaScript 大小，不包括 HTML、图片、样式、字体与数据接口，也不表示加载耗时减少同样比例。图谱和历史档案仅在打开图谱等入口时请求。

`node scripts/check-client-budget.mjs` 在生产构建后检查首页静态依赖图：上限 750,000 B，并禁止历史档案、游戏、图谱、战术和研究面板进入初始图。该图与浏览器实际请求可能因框架入口略有差异。

`data/archive-names.json` 是完整档案的中文姓名投影。采集脚本自动同步，也可运行 `node scripts/archive-names.mjs` 单独更新；离线测试校验译名没有遗漏或漂移。

异步面板有加载占位与失败后的重新载入入口。全局搜索和历史球员列表在需要时读取完整档案；数据与存档格式保持兼容。
