# 中文展示与原始身份

主界面统一使用中文，NBA、CBA、ESPN 及导出文件格式等标准标识保留原缩写。原始姓名仍用于身份、来源和英文检索；在球员档案中可主动展开查看。

## 数据

- `data/localization-corpus.json`：从公开球队名单采集的姓名与来源。
- `data/zh-glossary.json`：离线辅助译名工作表，不在页面运行期间调用翻译服务。
- `data/zh-curated.json`：校订和常用译名，优先级最高。新增专有名词可在此修订。
- `lib/localization.mjs`：归一化、译名选择、未收录姓名音译、状态与结构化事件摘要。

译名表属于展示层，不修改源 ID、统计、队伍身份或生涯年份。辅助译名不声称是官方中文姓名；未收录的新姓名采用音译，原始姓名可核实。采集脚本只处理公开体育资料，不处理私人信息，也不在生产环境中作为必需服务运行。

验证包含全部采集姓名、常见误译样本、重音和标点别名、状态、游戏日志、战术板与事件摘要。浏览器分别检查五大联赛名单、档案、图谱、战术、备课和游戏默认界面的文字。
